# Project case study

## Problem

Planning social posts across dates, formats, and media files can become scattered.

## Solution

A local desktop calendar and editor with portable media bundles and PDF exports.

## Implementation

Python, PyQt, and SQLite; Roman-inspired visual branding with a winged-message mark.

## Key decision

Local storage keeps the core planner independent of social-network credentials; publishing remains manual.

## Verification

The portfolio review passed 13 tests, including an offscreen interface check.

## Limitations

This is a planner, not an automatic publishing service. It does not provide cloud synchronization.

## Development approach

This portfolio includes AI-assisted implementation and review. The project documentation and commit history provide implementation context; this case study does not claim every line was written by hand.
