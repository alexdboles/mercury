# Verification and scope

The repository includes automated tests and GitHub Actions checks using Python 3.12.
Tests use temporary databases and fictional records; generated databases and exports are excluded from Git.

This is a local desktop portfolio application. There is no hosted service, account system,
automatic software updater, or multi-user synchronization. Run it on a computer with a graphical desktop.

Publication check: all 13 tests passed locally and on GitHub Ubuntu/Python 3.12, including offscreen Qt form interaction. The README image was captured from the real Mercury window.
